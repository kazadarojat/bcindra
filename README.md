## 项目简介

**BioSenses** 是一个教育项目，旨在帮助学习者理解感觉转导背后的分子与细胞机制。项目尝试通过交互式可视化和测验，让生物学通路更容易理解，而不仅仅依赖静态文字说明。

本项目适用于学习生理学、生物化学、神经科学及特殊感觉系统的学生。

> **教育声明：** BioSenses 是辅助学习工具，不能替代教科书、原始研究文献、课程资料或专业医疗建议。请使用可靠资料核对科学内容。

## 学习模块

项目开发记录中列出了六个感觉系统：

| 模块 | 主要学习内容 |
|---|---|
| 👁️ 视觉系统 | 光转导，以及光刺激如何转化为视网膜信号 |
| 🌡️ 皮肤感觉系统 | 与皮肤感觉相关的感觉转导机制 |
| 👃 嗅觉系统 | 气味检测涉及的分子信号传导 |
| 👅 味觉系统 | 味觉信号转导机制 |
| 🧭 前庭系统 | 头部运动与位置的感知 |
| 👂 耳蜗听觉系统 | 声音相关机械振动如何转化为神经信号 |

各模块的实际内容深度和覆盖范围可能会随着项目迭代而变化。

## 功能特色

开发记录中描述了以下学习功能：

- **可视化信号通路** —— 使用 2D SVG 动画展示生物学过程。
- **分步骤机制讲解** —— 将复杂的通路拆分为较易理解的阶段。
- **知识测验** —— 通过测验巩固学习内容。
- **学习进度记录** —— 开发记录提到，基于框架的实现包含本地进度存储。
- **独立 HTML 学习页面** —— 仓库中包含一个旨在独立运行的 `index.html` 文件。

独立 HTML 页面与 Next.js 实现所支持的功能可能不同。请先确认当前运行的版本，再依赖具体功能。

## 开始使用

### 方式一：打开独立 HTML 页面

如果你只想体验独立 HTML 页面：

1. 下载或克隆本仓库。
2. 使用现代浏览器打开 `index.html`。
3. 浏览可用模块并尝试交互功能。

不同浏览器中的行为可能略有差异。此方式无需启动 Next.js 开发服务器。

### 方式二：运行 Next.js 应用

你需要安装兼容的 Node.js 或 Bun 运行环境。

1. 克隆仓库：

   ```bash
   git clone https://github.com/kazadarojat/bcindra.git
   cd bcindra
   ```

2. 使用 Bun 安装依赖：

   ```bash
   bun install
   ```

3. 启动开发服务器：

   ```bash
   bun run dev
   ```

4. 在浏览器中打开 [http://localhost:3000](http://localhost:3000)。

**重要提示：** 运行框架应用前，请检查当前仓库结构。开发日志提到了 `src/` 目录，但该目录不一定存在于所有仓库版本中。如果应用无法启动，请确认所需源文件与配置文件是否齐全。

### 生产构建

`package.json` 中包含独立部署构建流程相关脚本：

```bash
bun run build
bun run start
```

生产启动脚本依赖构建生成的 standalone 输出。如果你的操作系统或 shell 不支持脚本中使用的命令语法，请检查并调整 `package.json` 中的脚本。

## 学习与科学准确性

BioSenses 旨在帮助学习者建立对感觉机制的概念性理解。学习一条信号通路时，建议能够识别：

1. 刺激或起始事件。
2. 检测刺激的受体、分子或细胞结构。
3. 细胞内信号传导步骤。
4. 膜电位变化或其他细胞反应。
5. 最终产生的神经信号或生理效应。

如将本项目用于学术学习，请为每个模块补充最新的生理学、生物化学教材及同行评审文献作为参考。应明确区分已确立的机制与为便于理解而简化的示意图，并在用于考核前核对测验答案的科学准确性。
